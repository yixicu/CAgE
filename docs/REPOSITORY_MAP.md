# Repository map

- `src/engine`: stable research facade and compatibility exports.
- `src/research`: explicit version registry, versioned contracts and separate scientific bundles.
- `src/agents`: role prompts and scientific-output validation.
- `src/runtime`: official Pi SDK adapter and backend-only model authorization.
- `src/storage`: Markdown/JSON/Git revisions and recoverable checkpoints.
- `src/tools`: authorized source reads and Worker-private notes.
- `src/server`: local REST/SSE service and application composition.
- `src/plugins`, `plugins`: minimal optional capabilities and a trusted example.
- `web`: browser UI; never the authoritative research state.
- desktop-packaging: native shell, setup, and build scripts.
